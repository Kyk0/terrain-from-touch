# Terrain from Touch — code

Simulation study of a sensing sole for the Booster K1. Models predict terrain class, friction, stiffness, and support state per foot.

- `fla_terrain/`: simulation, sensor schema, data loading, and models.
- `walking/`: walking policies used to generate data.
- `REPORT.md` and `REPORT_V2.md`: results and reproduction instructions.

Run scripts from this directory. Replace `/path/to/` paths with local dataset, model, and robot asset locations. Full datasets and trained models are not included.

Training scripts, configurations, checkpoint availability and reproduction commands: [TRAINING.md](TRAINING.md).
